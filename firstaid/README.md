# COOL X Wide（CPDAY11）系统急救包 FirstAid-V3

此包适用于已解锁引导器的酷派阔直板 COOL X Wide（CPDAY11），可将设备从自定义固件恢复至原厂 Android 16 的初始状态。刷写工具支持 Windows x64。

## 本次更新

- **回退镜像与刷写工具分开提供。** 原厂镜像分为两个 7z 分卷，Windows 刷写工具单独打包。
- **简化刷入流程。** 双击 `Flash.cmd` 后会请求管理员权限。开始页按 `Y`，确认页输入 `Yes`，即可进入刷写页。
- **自动安装 LK 驱动。** 刷写页检测到 LK 接口缺少 WinUSB 驱动时，会自动安装包内驱动、刷新 USB 设备列表，并确认驱动已绑定后继续。
- **完善 A/B 槽恢复。** 固定写入当前槽的另一槽，即 **A 刷 B、B 刷 A**。切换刷写模式后会重新确认活动槽，避免在槽位变化后继续写入。接受以 `k6789v1_64_` 开头的 LK 版本。
- **处理 OTA 快照和分区布局。** 恢复会先处理未完成的 OTA 快照，再清理 `super` 中两槽原有的系统布局并重建原厂分区表。目标槽写入完成后，工具会清除用户数据、激活目标槽并重启。

## 使用方法

**恢复会清除手机上的全部用户数据，包括照片、应用和 USB 调试授权。如有需要，请备份您的设备，急救不会导致Bootloader上锁。**

1. 下载两个 7z 分卷、刷写工具 ZIP 和 SHA-256 校验清单。将分卷放在同一目录，从 `.7z.001` 开始解压。
2. 解压工具 ZIP，将整个 `CPDAY11-FirstAid-Tools` 文件夹拖入 `CPDAY11-FirstAid-V3` 目录，与 `images` 文件夹放在同一级。
3. 将手机置于引导器 fastboot 或 Recovery 中的 fastbootd 模式，并连接电脑。
4. 双击工具文件夹中的 `Flash.cmd`，同意管理员授权。开始页按 `Y`，确认页输入 `Yes`，等待刷写完成。若失败，请复制报错页中的完整错误内容给开发者。
